# 🌤️ WeatherLy – Weather Dashboard

A responsive weather app built with **React, Vite, and Material UI**, powered by the OpenWeatherMap API.

🚀 **Live Demo:** [View WeatherLy](https://mini-project-react-material-60lwxhebf-no-team-0d25.vercel.app/)

💻 **GitHub:** [View Source Code](https://github.com/VedantGupta27/weatherly)

## ✨ Features

- 🌍 Search weather by city
- 🌡️ Temperature, humidity, feels-like, and min/max temperatures
- 🌦️ Dynamic weather images and icons
- 🌗 Automatic light/dark mode
- 📱 Responsive design
- ⚠️ Error handling for invalid cities

## 🧰 Tech Stack

- React + Vite
- Material UI (MUI) and MUI Icons
- CSS
- OpenWeatherMap API
- Vercel

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/VedantGupta27/weatherly.git
   cd weatherly
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root:

   ```env
   VITE_WEATHER_API_KEY=your_api_key_here
   ```

4. Start the app:

   ```bash
   npm run dev
   ```

Get your API key from [OpenWeatherMap](https://openweathermap.org/api).

**Security:** Keep `.env` out of GitHub. Variables prefixed with `VITE_` are visible in browser code.
